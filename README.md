## ✨ 核心亮點 (Features)
- 🎵 **Lofi 沉浸感音樂**：自帶毛玻璃質感的防驚嚇背景音樂控制鈕（支援跨瀏覽器 Autoplay 政策）。
- 💝 **高級感預載畫面**：跳動的呼吸愛心與完美的資源防閃爍預載 (Preloader)。
- 🎉 **漫天紙花拉炮**：驚喜揭曉與拍立得翻轉瞬間，支援效能優良的 Canvas Confetti 動畫。
- 📸 **原生滑動回憶相簿**：3D 傾斜拍立得卡片，搭配專屬站酷快樂手寫字體。
- ⌨️ **打字機告白信**：逐字列印的心意，引導使用者放慢腳步閱讀，字字句句充滿溫度。
- 📱 **Mobile First**：專為手機版直式體驗 100% 打造的完美 RWD 排版。

## 🛠️ 三分鐘客製化教學 (How to Customize)

這套系統使用了「內容與程式碼完全分離 (CMS-lite)」的先進架構。**您完全不需要懂 HTML/CSS 也能使用！** 所有的設定與文字都在一個設定檔內。

### 步驟 1：替換設定檔
1. 在您的專案底下，找到 `src/app/content.config.ts` 這個檔案。
2. 只要修改這個檔案裡面的「引號 `" "` 內容」，包含名字、情書各段落、以及相簿的說明文字。
3. 存檔後，網站上的內容就會全部自動更新！

### 步驟 2：替換您的專屬照片
1. 將原本放在 `src/assets/images/` 裡面的範例照片刪除。
2. 放入您們的合照，確保檔名（例如 `IMG_123.jpg`）與您在 `content.config.ts` 中設定的名稱一模一樣。
> [!TIP]
> 建議照片事前先壓縮過或是裁切成約莫 `1:1` 或 `4:3` 的大小，跑起來會更順暢喔！

### 步驟 3：替換背景音樂 (選用)
1. 準備一首可以逼哭對方的 `.mp3` 檔案，名稱改為 `lofi-bgm.mp3`。
2. 丟入 `src/assets/audio/` 資料夾中直接覆蓋原本的音檔即可！

## 🚀 部署教學 (Deployment)

### 選項 A：使用 Vercel 進行免費的「私人安全部署」 (強烈推薦)
如果您**不希望**情書與私密照片被全世界看到，請務必使用 Vercel。
1. 將本專案推送到您的 GitHub **Private Repository (私人資料庫)** 中。
2. 去 [Vercel](https://vercel.com/) 點擊 `Add New Project`。
3. 匯入您的 Private Repo (Vercel 免費版支援私有專案)。
4. Vercel 會自動偵測這是 Angular 專案，點擊 `Deploy`。
5. 兩分鐘後，您就會獲得一個能馬上傳給伴侶的安全專屬網址！

### 選項 B：使用 GitHub Pages 公開部署
如果您的照片都是大眾可見的，您也可以直接使用 GitHub 內建的免費網頁空間：
1. 確認您的專案為 **Public (公開)**。
2. 在終端機執行 `npm install -g angular-cli-ghpages`。
3. 執行部署指令：`ng deploy --base-href=/<您的Repo名稱>/`。
4. 您的網站就會活在 `https://<您的帳號>.github.io/<您的Repo名稱>/` 囉！
